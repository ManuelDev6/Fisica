# Fisica-Velocità

Una serie di programmi che calcolano rispettivamente tramite le varie formule inverse velocità,spazio e tempo.

## Serie di programmi

### 1-Velocità
Formula: Velocità = spazio / tempo

### 2-Spazio
Formula: Spazio = velocità * tempo

### 3-Tempo
Formula: Tempo = spazio / velocità
